# Make it yours — and trust-first defaults 🛡️

You're done — here's what to remember.

## Customize behavior

Open settings (`Cmd/Ctrl + ,`) and search **"Dusk Office"** to fine-tune:

- `duskOffice.applyFavoriteOnStartup` — auto-load your favorite theme when VS Code starts
- `duskOffice.rememberWorkspaceTheme` — per-workspace theme memory
- `duskOffice.autoSwitch.*` — day/night switching
- `duskOffice.adaptiveFocus.*` — language + time-aware adaptation
- `duskOffice.workspaceFingerprint.enabled` — auto-suggest variant for new projects
- `duskOffice.titleBar.alignWithTheme` — sync the title bar style with the active theme
- `duskOffice.statusBar.enabled` — show the Control Center button in the status bar

## Reset everything anytime

Don't like the changes? Run **`Dusk Office: Reset All Settings`** from the Command Palette. It will:

- Return to the VS Code default theme
- Reset product icons to default
- Reset activity bar position to default
- Clear all Dusk Office preferences and stored values
- Remove workspace-specific settings

## Privacy & trust

- **No telemetry** — no analytics, no remote calls
- **Local-only logic** — every feature runs in your VS Code instance
- **No companion installs** — Dusk Office never asks you to install another extension
- **GPL v3** — fork it, study it, contribute back

## Want a specific variant or to report a bug?

Open an issue on **[GitHub](https://github.com/SIDIKICONDE/dusk-office)**. Adding a new variant takes ~10 minutes thanks to the automated build pipeline (theme-sources → variant generators → WCAG validators).
