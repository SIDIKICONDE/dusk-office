# You're set up — now make it truly yours 🛡️

You've walked through everything Dusk Office can do. Here's your reference card
for the road ahead.

## Fine-tune behavior

Open settings (`Cmd/Ctrl + ,`) and search **"Dusk Office"**:

| Setting | What it controls |
| --- | --- |
| `applyFavoriteOnStartup` | Auto-load your favorite variant on editor start |
| `rememberWorkspaceTheme` | Each project remembers its own theme |
| `autoSwitch.*` | Day/night light ↔ dark switching schedule |
| `adaptiveFocus.*` | Language + time-aware automatic variant selection |
| `workspaceFingerprint.enabled` | Auto-suggest a variant for new projects |
| `titleBar.alignWithTheme` | Sync title bar color with the active theme |
| `statusBar.enabled` | Show or hide the Control Center button |

## Safety net — reset anytime

Run **`Dusk Office: Reset All Settings`** from the Command Palette. It will:

- Restore VS Code default theme, product icons, and activity bar position
- Clear all Dusk Office preferences and workspace-specific values
- Leave **zero residue** — your editor returns to exactly how it was before
