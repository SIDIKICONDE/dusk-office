# Welcome to Dusk Office 🌒

You just installed a **26-variant theme suite** for VS Code, Cursor and Windsurf — built for developers who spend long hours staring at code.

**What makes Dusk Office different:**

- **One coherent family** — all 26 variants share the same chrome philosophy, no random skins
- **Niche variants** — `Audit`, `Vault`, `Sentinel`, `Steward`, `Ledger`, `Voltage`, `Nocturne`, `Treasury`… each tuned for a specific work context
- **WCAG-verified terminal contrast** — every theme passes `4.5:1` on `terminal.foreground` and `2.9:1` on ANSI colors
- **Semantic highlighting** fully covered, not just TextMate scopes
- **Local-only behavior** — no telemetry, no companion installs, no network calls

This walkthrough takes ~2 minutes. You'll discover the theme picker, automatic project detection, day/night switching, and the Control Center.

When you're ready, click **"Apply the default Dusk Office theme"** below.
